\## 核心优势

\* \*\*高性能协议栈\*\*：纯 WebSocket 交互，告别内存消耗巨大的浏览器自动化工具。

\* \*\*算法全开源\*\*：包含最新的 `X-Bogus`, `X-Gnarly`, `strData` 核心签名算法源码，支持二次开发。
