# TikTok Live Scraper

A high-performance, protocol-level scraper for TikTok Live built on Python `asyncio`. No browser automation required.

[中文说明请见此处](README_CN.md)

## Key Features
* **Pure Protocol:** Built on WebSocket/Protobuf. Extremely low CPU/RAM usage.
* **Core Algorithms:** Includes source code for `X-Bogus`, `X-Gnarly`, and `strData` (WAF/Challenge bypass).
* **Structured Data:** Real-time parsing of Comments, Gifts, Likes, and Follows into clean JSON.
* **Stable:** Auto-reconnect, heartbeat maintenance, and msToken management.
